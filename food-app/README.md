# 📸 찰칵 영양 분석

음식 사진을 찍으면 AI가 음식을 알아보고 칼로리·영양소를 추정하고,
내 키·몸무게·나이·성별·활동량으로 계산한 권장 열량과 비교해 **아침·점심·저녁·간식으로 적정한지** 알려 주는 스마트폰용 웹앱입니다.

## 화면

| 탭 | 하는 일 |
|---|---|
| 📷 분석 | 끼니(아침/점심/저녁/간식) 선택 → 사진 찍기 또는 앨범에서 고르기 → 음식별 칼로리, 끼니 권장 열량 대비 %, "적정해요/많아요" 판정, 탄·단·지 균형, 당류·식이섬유·나트륨, AI 한 줄 조언. 음식별 양(×0.5~×2) 고치기, 잘못 찾은 음식 지우기 |
| 📅 오늘 기록 | 저장한 식사를 날짜별로. 하루 권장 열량 대비 %, 끼니별 막대, 나트륨 합계 |
| 👤 내 정보 | 성별·나이·키·몸무게·활동량 → 하루 권장 열량, 끼니별 배분, BMI |

## 계산 기준

- **하루 권장 열량**: 한국인 영양소 섭취기준(2020) 에너지필요추정량 공식 (3~18세, 19세 이상 남녀별, 신체활동계수 4단계)
- **끼니 배분**: 아침 25%, 점심 35%, 저녁 30%, 간식 10%
- **판정**: 끼니 권장 열량의 85~115% 적정, 60~85% 조금 부족, 60% 미만 부족, 115~140% 조금 많음, 140% 초과 많음
- **3대 영양소 적정 비율**: 탄수화물 55~65%, 단백질 7~20%, 지방 15~30%
- **나트륨**: 만성질환위험감소섭취량(1~2세 1,200 / 3~5세 1,600 / 6~8세 1,900 / 9세 이상 2,300mg)을 끼니 비율로 나눔
- **당류**: 끼니 열량의 20% 이하, **식이섬유**: 1,000kcal당 12g
- 음식 이름과 양, 영양소 값은 **AI가 사진으로 추정**한 값입니다. 판정 계산은 앱이 위 기준으로 직접 합니다.

## 설치 (약 10분)

1. **Gemini API 키 받기**: [aistudio.google.com](https://aistudio.google.com) → **Get API key** → 키 만들기 (무료)
2. [script.google.com](https://script.google.com) → **새 프로젝트** (구글 시트는 필요 없음)
3. `Code.gs`에 이 폴더의 `Code.gs` 붙여넣기
4. **파일 + → HTML** → 이름 `Index` → `Index.html` 붙여넣기
5. ⚙️ **프로젝트 설정 → 스크립트 속성 추가**
   - `GEMINI_API_KEY` = 1번에서 받은 키
   - (선택) `DAILY_LIMIT` = 하루 분석 횟수 한도 (기본 300)
   - (선택) `GEMINI_MODEL` = 쓸 모델 이름 (기본 `gemini-flash-latest`)
6. 함수 `setup` 실행 → 권한 허용 → 실행 로그에 "키 확인됨"
7. **배포 → 새 배포 → 웹 앱** → 실행 사용자 **나**, 액세스 **모든 사용자** → 주소를 휴대폰에서 열기
   - 휴대폰 브라우저 메뉴의 **홈 화면에 추가**를 누르면 앱처럼 쓸 수 있습니다.

## 데이터와 개인정보

- 키·몸무게 등 내 정보와 식사 기록은 **그 휴대폰 브라우저에만** 저장됩니다(서버·시트에 저장 안 함). 기록은 60일이 지나면 지워집니다.
- 사진은 분석할 때만 Gemini API로 보내고 저장하지 않습니다. 기록에는 작은 미리보기만 휴대폰에 남습니다.
- API 키는 Apps Script 안에만 있고 화면에 드러나지 않습니다. 다른 사람이 무료 사용량을 다 쓰지 않도록 하루 횟수 한도를 둡니다.
- 무료 Gemini API는 입력 내용이 구글의 서비스 개선에 쓰일 수 있습니다. 얼굴 등 개인정보가 사진에 나오지 않게 안내해 주세요.
