=====================================================================
 제미나이로 「알레르기 급식 안전 알리미」 만들기 - 간단 프롬프트
=====================================================================

[사용법]
1. 학교 구글 계정으로 새 구글 시트 → 확장 프로그램 → Apps Script 열기
2. gemini.google.com 새 채팅에 [프롬프트 1]을 통째로 붙여넣기
3. 제미나이가 준 Code.gs 와 Index.html 을 Apps Script 에 붙여넣기
   (Index 는 파일 옆 + → HTML → 이름 Index)
4. setup 함수 실행 → 실행 로그의 PIN 적어 두기
5. 배포 → 배포 테스트 → 웹 앱 URL 열어 확인
6. 되면 [프롬프트 2](PDF), 안 되면 [고치기 프롬프트]


------------------------- [프롬프트 1] 여기부터 복사 -------------------------
구글 Apps Script 웹앱을 만들어 줘. 초등학교 영양교사가 쓰는 "알레르기 급식 안전 알리미"야.
파일은 Code.gs 와 Index.html 두 개. 각각 처음부터 끝까지 전체 코드를 줘. "...", "생략" 없이.

[사용자 3종류 - 화면 위에 탭 3개]
1. 보호자 등록 (PIN 없음, 제출만 가능)
   - 학년(1~6)·반·번호·학생 이름, 알레르기 식품 체크(아래 19종), 반응 정도(가벼움/주의/심각), 에피펜 소지 여부, 증상 메모, 보호자 이름·연락처, 개인정보 수집 동의 체크
   - 제출하면 "승인 대기" 상태로 저장
2. 선생님 공유 (교직원 PIN, 보기만)
   - 날짜별(이번 주 월~금 버튼, 지난주/다음주)로 "알레르기 주의 학생"을 반별로 보여 줌
   - 학생마다: 위험 메뉴, 걸리는 알레르기, 정해진 대체식(없으면 "대체식 준비 중"), 에피펜·심각 표시
   - 위에 요약: 주의 학생 수, 위험 메뉴 수, 대체식 미정 수, 대체식 준비 수량(예: 두유 3)
   - 학급 필터, 인쇄 버튼, 급식실 모니터용 큰 글씨 모드
   - 보호자 연락처는 보이지 않게
3. 영양교사 (영양교사 PIN) - 안에 메뉴 3개
   a) 학생 명단: 승인 대기 학생 승인/수정/반려, 승인된 학생 수정/삭제, 직접 추가
   b) 식단 입력: 날짜 고르고 NEIS 식단을 붙여넣으면 "쇠고기미역국(5.6.16)", "돈육떡갈비 1.2.5.6.10.13." 처럼 메뉴 뒤 알레르기 번호를 자동으로 읽어 표로 보여 줌.
      번호가 없는 메뉴는 이름으로 추정(우유→2, 계란→1, 새우→9, 돼지→10 …)하고 "추정·확인 필요" 표시. 표에서 고칠 수 있고 저장.
      저장된 식단 날짜 목록을 달별 버튼으로 보여 줘서 누르면 그 날로 이동.
   c) 위험 체크·대체식: 고른 날의 식단과 승인된 학생 알레르기를 자동 대조해 메뉴별로 위험 학생을 보여 줌.
      메뉴마다 대체식 후보를 추천(예: 우유→두유·쌀음료, 계란말이→두부찜·애호박볶음, 새우튀김→닭가슴살·쌀가루 반죽, 돼지고기→닭고기, 김치(새우젓)→백김치).
      중요: 후보에 그 학생의 다른 알레르기가 들어 있으면 "⚠ ○○ 불가"로 경고(예: 우유·대두 둘 다 있는 학생에게 두유 안 됨).
      후보를 누르면 안전한 학생 모두에게 적용, 학생별로 직접 입력도 가능, 대체식 수량 자동 집계, "저장하고 선생님들께 공유" 버튼.
      주간 버튼에 날마다 주의 학생 수와 "미정 N건" 표시.

[알레르기 19종 - 학교급식 표시 번호]
1 난류(달걀) 2 우유 3 메밀 4 땅콩 5 대두 6 밀 7 고등어 8 게 9 새우 10 돼지고기
11 복숭아 12 토마토 13 아황산류 14 호두 15 닭고기 16 쇠고기 17 오징어 18 조개류 19 잣

[저장 - 이 스크립트가 붙은 구글 시트]
- 탭: students(학생), meals(날짜별 식단, 메뉴는 JSON), plans(날짜·메뉴·학생별 대체식)
- 칸 서식은 일반 텍스트로 해서 전화번호 0, 날짜가 바뀌지 않게
- 화면과 서버 사이에 Date 객체를 보내지 말고 'yyyy-MM-dd' 문자열로
- 쓰기 작업은 LockService 로 잠그기

[PIN]
- 스크립트 속성 ADMIN_PIN(영양교사), STAFF_PIN(교직원)
- setup() 함수: 시트 탭 만들고, PIN 이 없으면 6자리 무작위로 만들어 실행 로그에 보여 줌
- 서버 함수마다 PIN 을 다시 확인 (영양교사 기능은 ADMIN_PIN 만)
- 로그인한 PIN 은 sessionStorage 에 기억

[화면]
- 차분한 초록색, 카드 모양, 휴대폰에서도 잘 보이게, 모두 한국어
- 프레임워크 없이 HTML·CSS·자바스크립트만, 서버 호출은 google.script.run
- 사용자가 입력한 글자는 화면에 넣을 때 HTML 이스케이프
- doGet 은 HtmlService.createHtmlOutputFromFile('Index'), 제목과 viewport 메타태그 포함

마지막에 설치 방법(붙여넣기, setup 실행, 웹앱 배포: 실행 사용자 나, 액세스 모든 사용자)을 짧게 알려 줘.

------------------------- [프롬프트 2] 여기부터 복사 -------------------------
잘 됐어. 이제 영양교사 "식단 입력"에 식단표 PDF 올리기 기능을 추가해 줘.
- 학교 식단표 PDF(한 달 달력 모양 또는 한 주 모양)를 고르면 브라우저에서 pdf.js
  (https://cdn.jsdelivr.net/npm/pdfjs-dist@3.11.174/build/pdf.min.js, 한글용 cMapUrl 은 같은 주소의 cmaps/)로 글자와 위치를 읽어
  요일 머리글(월·화·수·목·금)로 칸을 나누고, 칸 안 날짜 숫자 아래 줄들을 그 날 메뉴로 만든다.
- 몇 월인지는 PDF 제목의 "11월" 같은 글자와, 날짜와 요일이 맞는지로 판단.
- 열량·단백질·원산지 줄은 버리고, "개교기념일·재량휴업" 같은 날은 빼기. 메뉴 뒤 작은 알레르기 번호는 메뉴에 붙이기.
- 저장 전에 날짜별로 확인 화면: 날짜 체크박스, 메뉴를 고칠 수 있는 칸, 그 날 주의 학생 이름, 이미 저장된 날이면 "덮어씀" 표시. "선택한 N일 저장" 한 번에.
- 원본 PDF 는 구글 드라이브 폴더에 저장하고(링크로 보기 가능), 선생님 공유 화면에 "N월 식단표 원본 PDF 보기" 링크 표시.
- 글자가 없는 스캔 PDF 면 "글자를 읽을 수 없는 PDF입니다. 붙여넣기를 이용해 주세요" 안내.
바뀐 Code.gs 와 Index.html 을 각각 전체로 다시 줘.
