# 제미나이로 만드는 「알레르기 급식 안전 알리미」 실습 프롬프트

영양교사 연수용. 무료 제미나이도 끝까지 만들 수 있도록 **앱을 파일 9개로 나누고, 프롬프트 하나에 파일 하나씩** 만듭니다.
프롬프트는 회색 상자 안의 글을 **처음부터 끝까지 그대로** 복사해서 붙여넣으세요.

---

## 시작 전 준비 (5분)

1. **학교 구글 계정**으로 새 구글 시트를 만듭니다. 이름 예: `알레르기 급식 알리미 실습`
2. 시트 메뉴 **확장 프로그램 → Apps Script**를 엽니다. 이 창은 실습 내내 열어 둡니다.
3. **gemini.google.com**에서 **새 채팅 하나**를 엽니다. **모든 단계를 이 채팅 하나에서** 진행합니다. (앞 단계에서 정한 이름을 기억하게 하려고)
4. 메모장을 하나 열어 둡니다. 잘 된 코드를 백업해 두는 용도입니다.

## 매 단계 진행 방법 (모든 단계 똑같음)

1. 이 문서의 프롬프트를 복사해 제미나이에 붙여넣습니다.
2. 제미나이 답의 **코드 상자 오른쪽 위 "복사" 버튼**을 누릅니다. (드래그로 복사하면 빠지는 부분이 생깁니다)
3. Apps Script에서 파일을 엽니다.
   - `Code.gs`는 처음부터 있습니다.
   - HTML 파일은 **파일 옆 `+` → HTML** 을 누르고 **이름만** 씁니다. 예: `Index` (`.html`은 자동으로 붙음, 대소문자 정확히)
4. 파일 안에서 **Ctrl+A → Ctrl+V → Ctrl+S** (전체 선택, 붙여넣기, 저장)
5. 화면 확인: **배포 → 배포 테스트 → 웹 앱 URL** 을 새 탭에서 엽니다.
   - 이 주소는 한 번만 열어 두면 됩니다. 코드를 저장한 뒤 **그 탭을 새로고침**하면 바로 반영됩니다.
6. 안 되면 맨 아래 **[고치기 프롬프트]** 를 씁니다. 그래도 안 되면 강사가 주는 **정답 파일**을 붙여넣고 다음 단계로 갑니다.

## 1단계. Code.gs (서버)

**붙여넣을 곳:** Apps Script의 `Code.gs` (원래 있던 내용은 지우고)
**확인:** 위쪽 함수 선택에서 `setup` → ▶ 실행 → 권한 허용("고급 → 안전하지 않음으로 이동") → 시트에 탭 4개, 실행 로그에 PIN 2개. **PIN을 메모장에 적어 두세요.**

```text
[1단계] Code.gs 파일 전체를 만들어 줘.

■ 시트 (탭 이름: 첫 줄 머리글을 이 순서 그대로)
- students: id, grade, classNo, number, name, allergens, severity, epipen, memo, guardian, contact, status, createdAt, updatedAt
- meals: date, menus, updatedAt
- plans: date, menu, studentId, substitute, updatedAt
- files: month, name, url, fileId, uploadedAt

■ 저장 규칙
- SpreadsheetApp.getActiveSpreadsheet() 를 쓴다. 탭이 없으면 머리글을 넣어 새로 만든다(머리글 굵게, 첫 줄 고정).
- 값을 쓸 때 그 칸들의 서식을 일반 텍스트(setNumberFormat('@'))로 먼저 바꾸고 넣는다.
- allergens 와 menus 는 JSON 문자열로 저장하고, 읽을 때 JSON.parse 해서 배열로 돌려준다. (빈 칸이면 [])
- 글자가 = + - @ 로 시작하면 앞에 작은따옴표(')를 붙여 저장한다. (수식 방지)
- 읽을 때: 칸 값이 Date 면 문자열로 바꾼다(date 열은 'yyyy-MM-dd', month 열은 'yyyy-MM', 나머지는 'yyyy-MM-dd HH:mm:ss').
  grade, classNo, number 는 숫자로, students 의 epipen 은 'true' 이면 true 아니면 false(불리언)로, 나머지는 문자열로. 완전히 빈 줄은 건너뛴다.
- 화면으로 돌려주는 값에는 Date 객체를 절대 넣지 않는다. (google.script.run 이 Date 를 못 보냄)
- 도우미 함수: rows_(탭이름) = 2번째 줄부터 전체를 객체 배열로 읽기, writeAll_(탭이름, 배열) = 2번째 줄부터 지우고 배열 전체를 다시 쓰기, append_(탭이름, 객체) = 맨 아래 한 줄 추가.
- 쓰기 작업은 withLock_(fn) 안에서 한다: LockService.getScriptLock().waitLock(10000) 후 fn 실행, finally 에서 releaseLock.
- stamp_() = 지금 시각 'yyyy-MM-dd HH:mm:ss' (Session.getScriptTimeZone() 기준).

■ PIN (스크립트 속성 ADMIN_PIN = 영양교사, STAFF_PIN = 교직원)
- role_(pin): ADMIN_PIN 과 같으면 'admin', STAFF_PIN 과 같으면 'staff', 아니면 오류 'PIN이 올바르지 않습니다.'
  틀린 횟수를 CacheService.getScriptCache() 에 'pinFails' 로 600초 동안 세고, 20번 이상이면 'PIN 오류가 너무 많습니다. 10분 뒤에 다시 시도하세요.' 오류.
- needAdmin_(pin): role_(pin) 이 'admin' 이 아니면 오류 '영양교사 PIN이 필요합니다.'

■ 학생 입력 검사 cleanStudent_(d): 정리된 객체를 돌려주고, 틀리면 한국어 오류
- grade 1~6, classNo 1~30, number 1~60 (숫자로 변환), name 필수(앞뒤 공백 제거, 20자까지)
- allergens: 1~19 숫자만, 중복 제거, 오름차순, 최소 1개 ('알레르기 종류를 한 가지 이상 선택해 주세요.')
- severity: 'mild','caution','severe' 중 하나, 아니면 'caution'
- epipen: true 또는 'true' 이면 문자열 'true', 아니면 'false'
- memo 200자, guardian 20자, contact 20자 (앞뒤 공백 제거)

■ 함수 (이 이름 그대로. 화면에서 google.script.run 으로 부른다)
1) doGet(): HtmlService.createTemplateFromFile('Index').evaluate() 를 돌려준다. setTitle('알레르기 급식 안전 알리미'), addMetaTag('viewport','width=device-width, initial-scale=1').
2) include(name): HtmlService.createHtmlOutputFromFile(name).getContent() 를 돌려준다. 그 파일이 아직 없어서 오류가 나면 '' 를 돌려준다.
3) setup(): 탭 4개를 만들고, ADMIN_PIN·STAFF_PIN 이 없으면 6자리 무작위 숫자로 만든 뒤, Logger.log 로 '영양교사 PIN(ADMIN_PIN): …', '교직원 PIN(STAFF_PIN): …' 을 보여 준다.
4) login(pin): role_(pin) 결과('admin' 또는 'staff')를 돌려준다.
5) submitStudent(data): PIN 없이 누구나. cleanStudent_ 후 id = Utilities.getUuid(), status = 'pending', createdAt·updatedAt = stamp_() 를 넣어 students 에 추가하고 id 를 돌려준다.
6) getAdminData(pin): 영양교사만. { students, meals, plans, files } 각 탭 전체.
7) getStaffData(pin, from, to): 두 PIN 모두 가능. 돌려줄 값:
   { students: status 가 'approved' 인 학생만, 그리고 guardian·contact 는 뺀 객체,
     meals: date 가 from 이상 to 이하, plans: date 가 from 이상 to 이하, files: 전체, mealDates: meals 탭의 모든 date 배열 }
8) saveStudent(pin, data): 영양교사만. cleanStudent_ 후, data.id 와 같은 학생이 있으면 내용을 바꾸고 updatedAt 갱신, 없으면 새 id 와 status 'approved' 로 추가. true.
9) setStudentStatus(pin, id, status): 영양교사만. status 는 'approved','rejected','pending' 만 허용. true.
10) deleteStudent(pin, id): 영양교사만. 그 학생 줄과 plans 의 studentId 가 같은 줄을 모두 삭제. true.
11) saveMeals(pin, list): 영양교사만. list = [{ date:'yyyy-MM-dd', menus:[{ name, allergens:[숫자] }] }].
    날짜 형식을 검사하고, 메뉴 이름은 공백 제거·40자, allergens 는 1~19 정리. list 에 있는 날짜의 기존 식단은 지우고 메뉴가 1개 이상인 날만 새로 넣는다. 날짜순 정렬. 저장한 날 수를 돌려준다.
12) saveMeal(pin, date, menus): saveMeals(pin, [{ date, menus }]) 를 돌려준다.
13) savePlans(pin, date, plans): 영양교사만. plans = [{ menu, studentId, substitute }]. plans 탭에서 그 date 줄을 모두 지우고, substitute 가 비어 있지 않은 것만(60자까지) date·updatedAt 을 붙여 새로 넣는다. true.
14) uploadMenuPdf(pin, month, name, base64): 영양교사만. month 는 'yyyy-MM' 형식 검사.
    Utilities.base64Decode 한 크기가 10MB 를 넘으면 오류 'PDF 파일은 10MB 이하만 올릴 수 있습니다.'
    드라이브 폴더 '알레르기 급식 알리미 - 식단표' 에 PDF 로 저장한다(폴더 id 는 스크립트 속성 MENU_FOLDER_ID 에 기억, 없거나 못 찾으면 새로 만듦).
    file.setSharing(DriveApp.Access.ANYONE_WITH_LINK, DriveApp.Permission.VIEW) 를 시도하고, 오류면 DOMAIN_WITH_LINK 로 다시 시도, 그것도 오류면 그냥 넘어간다.
    files 탭에서 같은 month 의 옛 파일은 휴지통으로 보내고(setTrashed(true)), 그 줄을 { month, name, url, fileId, uploadedAt } 새 줄로 바꾼다. 파일 url 을 돌려준다.
```

## 2단계. Index.html (뼈대와 공통 도구)

**붙여넣을 곳:** `+ → HTML` → 이름 `Index`
**확인:** 배포 → 배포 테스트 → 웹 앱 URL 열기 → 탭 3개가 보이고, 누르면 "아직 만들지 않은 화면입니다"가 나오면 성공. (디자인은 3단계에서 입힘)

```text
[2단계] Index.html 파일 전체를 만들어 줘. 이 파일은 화면 뼈대와, 다른 파일들이 같이 쓰는 공통 함수를 가진다.

■ 파일 순서 (꼭 이 순서)
1) <head>: <base target="_top">, charset utf-8, viewport 메타, <title>알레르기 급식 안전 알리미</title>, 그리고 다음 한 줄
   <?!= include('Style'); ?>
2) <body> 화면 구조: 아래 HTML 을 id, class, data- 속성까지 그대로 쓴다.
<header>

  <nav class="tabs" id="tabs">
    <button data-tab="register">보호자 등록</button>
    <button data-tab="staff">선생님 공유</button>
    <button data-tab="admin">영양교사</button>

</header>
<button class="btn exit-monitor" onclick="setMonitor(false)">모니터 모드 끄기</button>

  </section>
  <section id="view-staff" class="hidden">
    <div id="staff-login" class="card hidden"></div>
    <div id="staff-body" class="hidden"></div>
  </section>

    <div id="admin-body" class="hidden">
      <div class="subtabs no-print" id="admin-tabs">
        <button data-sub="plan">위험 체크·대체식</button>
        <button data-sub="meal">식단 입력</button>
        <button data-sub="students">학생 명단</button>
      </div>

    </div>
  </section>
</main>
<div id="modal" class="modal hidden"></div>
3) 공통 함수가 든 <script> (아래 목록)
4) 그다음 줄마다 하나씩:
   <?!= include('Register'); ?>
   <?!= include('Staff'); ?>
   <?!= include('Admin'); ?>
   <?!= include('Meal'); ?>
   <?!= include('Plan'); ?>
   <?!= include('Pdf'); ?>
5) 마지막 <script>: route(); 한 줄.
※ 이 파일 안에는 위 include 줄 말고는 "<?" 나 "?>" 글자가 절대 들어가면 안 된다. (Apps Script 가 명령으로 착각함)
```

## 9단계. Pdf.html (식단표 PDF 올리기) — 도전 과제

**붙여넣을 곳:** `+ → HTML` → 이름 `Pdf`
**확인:** "식단 입력" 맨 위 "식단표 PDF 올리기"에서 학교 식단표 PDF 선택 → 날짜별 메뉴 목록이 나오면 확인 후 "선택한 N일 식단 저장".
> 가장 어려운 단계입니다. 무료 제미나이가 잘 못 만들면 정답 파일을 쓰세요. 스캔한 그림 PDF는 원래 읽을 수 없습니다.

```text
[9단계] Pdf.html 파일 전체를 만들어 줘. <script> 하나만 들어 있어야 해.
식단표 PDF 를 브라우저에서 pdf.js 로 읽어 날짜별 메뉴를 뽑고, 확인 화면을 거쳐 저장한다.

■ pdf.js 불러오기
- PDFJS_BASE = 'https://cdn.jsdelivr.net/npm/pdfjs-dist@3.11.174/'
- loadPdfJs(): window.pdfjsLib 이 있으면 그대로, 없으면 <script src=PDFJS_BASE+'build/pdf.min.js'> 를 붙이고 다 읽히면
  pdfjsLib.GlobalWorkerOptions.workerSrc = PDFJS_BASE + 'build/pdf.worker.min.js' 후 돌려준다(한 번만 불러오게). 실패하면 오류 'PDF 읽기 도구를 불러오지 못했습니다. 인터넷 연결을 확인해 주세요.'

■ 정규식 (그대로)
PDF_HEADER = /^\(?\s*([월화수목금토일])\s*\)?(요일)?$/
PDF_MARK_MD = /^(\d{1,2})\s*[\/.월]\s*(\d{1,2})\s*일?\s*(?:\(?\s*([월화수목금토일])(?:요일)?\s*\)?)?$/
PDF_MARK_D = /^(\d{1,2})\s*일?\s*(?:\(?\s*([월화수목금토일])(?:요일)?\s*\)?)?$/
PDF_SKIP = /kcal|칼로리|열량|단백질|탄수화물|지방|칼슘|철분|비타민|나트륨|원산지|식단표|유발식품|영양소|^[중석조]식$|[:：]/i
PDF_HOLIDAY = /휴업|재량|기념일|방학|공휴일|휴일|급식\s*없음|미실시|단축/

■ 함수
1) pdfMarker(text): 공백 정리 후 PDF_MARK_MD 가 맞고 월 1~12·일 1~31 이면 { m, d, dow(요일 글자 또는 null) },
   아니면 PDF_MARK_D 가 맞고 일 1~31 이면 { m:null, d, dow }, 아니면 null. (날짜 칸의 "3", "11/9(월)" 같은 글자를 알아봄)
2) pdfLines(items): 글자 조각 item = { s, x, y, w, h }. y 가 큰 것(위쪽)부터 정렬해서, y 차이가 max(2.5, 0.45×큰 글자높이) 이하인 조각끼리 한 줄로 묶는다.
   줄 안에서는 x 순으로 이어 붙이되, 앞 조각 끝(x+w)과 다음 조각 x 사이가 max(1.5, 0.2×h) 보다 크면 띄어쓰기를 넣는다. [{ y, text }] 위→아래 순, 빈 줄 제외.
3) pdfColumns(items): 요일 칸 나누기.
   - 머리글 후보 = 글자가 PDF_HEADER 에 맞거나, pdfMarker 결과에 요일(dow)이 있는 조각.
   - 후보를 y 차이 3 이하끼리 묶고, 그 묶음 안에서 x 위치가 서로 다른(Math.round(x/20) 기준) 것이 3개 이상인 묶음 중 가장 위의 것을 머리글 줄로 쓴다.
   - 머리글이 있으면: 머리글 조각마다 칸 = { cx: x+w/2, dow: 요일 글자, items: [] }, cx 순 정렬. 모든 조각을 가운데(x+w/2)가 가장 가까운 칸에 넣는다(이웃 칸 cx 의 중간값을 경계로).
     머리글이 없으면 칸 하나(dow null)에 모든 조각.
   - 칸마다 pdfLines 로 줄을 만들고 위에서부터: pdfMarker 가 맞는 줄이면 새 구간 { mark, text, lines:[] } 시작, 아니면 마지막 구간의 lines 에 추가(첫 날짜 전 줄은 버림).
   - [{ dow, segs }] 를 돌려준다.
4) pdfResolve(mark, colDow, ym): 월 = mark.m || ym.m, 연 = ym.y (12월 식단에 1월 날짜면 +1, 1월 식단에 12월 날짜면 −1). 없는 날짜면 null.
   기대 요일(mark.dow || colDow)이 있는데 실제 요일(DOW[getDay()])과 다르면 null. 맞으면 'yyyy-MM-dd'.
5) pdfPickMonth(allText, cols): 후보 연·월을 모아 점수가 가장 높은 것을 고른다.
   후보: 글에서 /(20\d{2})\s*[년.\-\/]\s*(\d{1,2})\s*월/ (가산점 1), /(?:^|[^\d])(\d{1,2})\s*월(?![요])/ 의 월에 올해·내년·작년(가산점 0.5, 0.4, 0.3), 그리고 이번 달 기준 −1~+2 달(이번 달·다음 달 0.2, 나머지 0).
   점수 = 가산점 + pdfResolve 가 성공하는 구간 수. { y, m } 반환.
6) pdfCellMenus(lines): 줄마다 앞의 기호(* # @ ♣ ☆ ★ ◆ ◇ ■ □ ▶ · • - 공백) 지우고, PDF_HOLIDAY 면 holiday 로 기억하고 건너뜀,
   숫자·점·쉼표·괄호만 있는 줄은 바로 앞 메뉴 줄 뒤에 띄어쓰기로 붙임(작은 글씨 알레르기 번호), PDF_SKIP 이면 건너뜀, 나머지는 메뉴 줄. { text: 메뉴 줄들을 줄바꿈으로, holiday }
7) readMenuPdf(buffer): pdfjsLib.getDocument({ data: buffer, cMapUrl: PDFJS_BASE + 'cmaps/', cMapPacked: true }) 로 모든 쪽의 getTextContent() 를 읽어
   item 을 { s: str, x: transform[4], y: transform[5], w: width, h: Math.abs(transform[3]) || height || 8 } 로 바꾸고(빈 글자 제외) 쪽마다 pdfColumns.
   글자가 하나도 없으면 오류 'PDF에서 글자를 읽을 수 없습니다. 스캔한 그림 파일인 것 같아요. 한글·엑셀 원본에서 "PDF로 저장"한 파일을 올리거나, 아래 붙여넣기 칸을 이용해 주세요.'
   ym = pdfPickMonth. 칸마다 구간을 위에서부터 보며 date = pdfResolve 가 있고 앞 날짜보다 뒤면 그 날짜의 줄 묶음에 넣고, 아니면(날짜처럼 보이는 숫자 줄) 앞 날짜 묶음에 구간 글자와 줄을 그대로 붙인다.
   날짜순으로 pdfCellMenus 를 적용해 [{ date, text, holiday, include: text 가 있으면 true }]. 하나도 없으면 오류 '식단표에서 날짜를 찾지 못했습니다. 요일(월·화·수…)과 날짜가 표시된 식단표인지 확인해 주세요.'
   { y, m, days } 반환.
8) fileToBase64(file): FileReader.readAsDataURL 후 쉼표 뒤 부분을 돌려주는 Promise
9) pdfCardHTML(): 카드 "📄 식단표 PDF 올리기" + 설명 + input type="file" id="pdf-file" accept=".pdf" + 체크박스 id="pdf-attach"(state.pdfAttach 면 체크) "원본 PDF를 선생님 공유 화면에 첨부" + <div id="pdf-status"></div>
   + state.admin.files 가 있으면 "첨부된 식단표:" 링크들(새 창).
   state.pdfImport 가 있으면 확인 카드 추가: 제목 "{파일이름} → {y}년 {m}월, {N}일 찾음", 설명(메뉴 한 줄에 하나, 번호는 메뉴 뒤, 추정은 꼭 확인), "전체 선택"(data-pdf="all")·"전체 해제"(data-pdf="none"),
   날마다 <div class="pdf-day"> (include 가 false 면 class off): 머리에 체크박스(data-inc=순번) + fmtDate, 이미 저장된 날이면 badge "기존 식단 덮어씀", holiday 면 회색 badge,
   parseMenuText(text) 결과와 approved() 학생이 겹치면 빨간 "주의 N명: 이름들". 몸통 .pdf-day-body 왼쪽 textarea(data-txt=순번, 값 text), 오른쪽 메뉴마다 이름 + (guessed 면 추정 chip) + chips.
   맨 아래 버튼 id="pdf-save" "선택한 N일 식단 저장"(선택 0이면 disabled), id="pdf-cancel" "취소".
10) wirePdf(c): pdf-attach change → state.pdfAttach. pdf-file change → 10MB 넘으면 빨간 안내, 아니면 '#pdf-status' 에 'PDF를 읽는 중…' →
    state.pdfImport = { ...await readMenuPdf(await file.arrayBuffer()), fileName: file.name, base64: await fileToBase64(file) } → renderMeal(). 오류는 #pdf-status 에 빨간 글씨.
    pdfImport 가 있을 때: 전체 선택/해제(메뉴가 있는 날만 선택), 체크박스·textarea change → 값 바꾸고 renderMeal(), 취소 → state.pdfImport = null, renderMeal().
    저장 → 선택한 날을 { date, menus: parseMenuText(text) } 로. confirm 에 'N일 식단을 저장할까요?' + 덮어쓸 날 수 + 추정 메뉴 수 안내.
      버튼 잠그고 await call('saveMeals', state.adminPin, [{ date, menus:[{name, allergens}] }])
      state.pdfAttach 면 await call('uploadMenuPdf', state.adminPin, 'yyyy-MM', 파일이름, base64)
      state.admin = await call('getAdminData', state.adminPin), state.staff/pdfImport/mealDraft/draft = null, state.planDate = 첫 날짜, state.sub = 'plan', renderAdmin(), toast('N일 식단을 저장했습니다. 위험 학생을 확인하세요.')
      오류는 alert 하고 버튼 풀기.
```
