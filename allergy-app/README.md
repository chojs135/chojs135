# 🍱 알레르기 급식 안전 알리미

초등학교용 급식 알레르기 관리 웹앱입니다. 구글 시트와 Apps Script로 만들었습니다.
함께학교 정책제안 「AI 기반 학교 급식 알레르기 학생 관리 시스템」을 실제 학교에서 바로 쓸 수 있는 규모로 줄여 구현했습니다.

## 누가 무엇을 하나요

| 사용자 | 화면 | 하는 일 |
|---|---|---|
| 보호자 | **보호자 등록** | 학년·반·번호·이름, 알레르기 식품(1~19번), 반응 정도, 에피펜 여부를 미리 등록 (PIN 없음, 제출만 가능) |
| 영양교사 | **영양교사 › 학생 명단** | 보호자가 제출한 정보를 확인해 승인·수정·반려 |
| 영양교사 | **영양교사 › 식단 입력** | NEIS 식단표를 붙여넣으면 알레르기 번호를 자동으로 읽음. 번호가 없는 메뉴는 이름으로 추정해 "확인 필요" 표시 |
| 영양교사 | **영양교사 › 위험 체크·대체식** | 식단과 학생을 자동으로 대조해 위험 학생을 미리 체크. 메뉴마다 대체식을 추천하고, 그 학생의 다른 알레르기와 겹치면 경고 (예: 우유·대두 알레르기 학생에게 두유 ⚠). 확정하면 대체식 수량이 자동 집계됨 |
| 담임·교과 선생님 | **선생님 공유** | 날짜별·반별로 누가, 어떤 메뉴가, 무슨 대체식인지 조회. 급식실 모니터 모드(큰 글씨)와 인쇄 지원. 보호자 연락처는 보이지 않음 |

## 먼저 체험해 보기 (데모 모드)

`Index.html` 파일을 내려받아 브라우저로 열면 예시 학생 6명과 이번 주 식단이 들어 있는 데모 모드로 실행됩니다.

- 영양교사 PIN `1234`, 교직원 PIN `0000`
- 데모 데이터는 그 브라우저에만 저장되고, 화면 위쪽 버튼으로 초기화할 수 있습니다.

## 우리 학교에 설치하기 (약 10분)

1. **학교 구글 계정**으로 새 구글 시트를 만듭니다. (예: `2026 알레르기 급식 관리`)
2. 메뉴 **확장 프로그램 › Apps Script**를 엽니다.
3. 기본으로 있는 `Code.gs` 내용을 지우고 이 폴더의 `Code.gs`를 붙여넣습니다.
4. 왼쪽 **파일 +** › **HTML**로 `Index` 라는 파일을 만들고 `Index.html` 내용을 붙여넣습니다.
5. 위쪽 함수 선택 상자에서 `setup`을 고르고 **실행**합니다. 권한 승인 창이 뜨면 허용합니다.
   - 시트에 `students`, `meals`, `plans` 탭이 생깁니다.
   - **실행 로그**에 영양교사 PIN과 교직원 PIN이 표시됩니다(6자리 무작위).
6. PIN을 바꾸려면 **프로젝트 설정(톱니바퀴) › 스크립트 속성**에서 `ADMIN_PIN`, `STAFF_PIN` 값을 수정합니다.
7. **배포 › 새 배포 › 유형: 웹 앱**을 선택합니다.
   - 실행 사용자: **나**
   - 액세스 권한: 보호자도 들어와야 하므로 **모든 사용자**
8. 나온 웹 앱 주소를 안내합니다.
   - 보호자: 가정통신문·알리미에 주소(또는 QR코드)를 넣어 안내 → **보호자 등록** 탭 사용
   - 선생님: 메신저로 주소와 교직원 PIN 안내 → **선생님 공유** 탭 사용

> 코드를 고친 뒤에는 **배포 › 배포 관리 › 수정(연필) › 버전: 새 버전**으로 다시 배포해야 반영됩니다.

## 데이터와 개인정보

- 모든 데이터는 **학교 구글 계정의 시트 한 곳**에만 저장됩니다. 외부 서버나 AI 서비스로 보내지 않습니다.
- 보호자 등록 화면은 **제출만** 가능하고, 다른 학생 정보는 볼 수 없습니다.
- 선생님 공유 화면에는 보호자 이름·연락처가 나오지 않습니다.
- PIN을 20번 틀리면 10분 동안 로그인이 막힙니다. PIN은 6자리 이상으로 쓰고, 학기마다 바꾸는 것을 권장합니다.
- 학년도가 끝나면 시트의 `students` 탭을 정리(삭제)하세요. 등록 화면 안내 문구의 보관 기간과 학교 개인정보 처리 방침을 맞춰 주세요.
- 대체식 추천과 메뉴명 추정은 **일반적인 식재료 기준의 보조 기능**입니다. 실제 제품 원재료와 교차오염 여부는 영양교사가 최종 확인해야 합니다.

## 파일 구성

| 파일 | 내용 |
|---|---|
| `Code.gs` | 서버: 시트 읽기·쓰기, PIN 확인, 입력값 검사 |
| `Index.html` | 화면 전체(보호자 등록, 선생님 공유, 영양교사). Apps Script 밖에서 열면 데모 모드 |
| `appsscript.json` | Apps Script 설정(시간대: 서울, 웹앱 공개 범위). 편집기에서 "appsscript.json 표시"를 켰을 때만 필요 |

## 연수에서 이어서 만들어 볼 기능 (바이브코딩 실습 과제)

- 아침에 오늘 위험 학생 목록을 담임 선생님 메일로 자동 발송 (Apps Script 트리거 + `MailApp`)
- 한 주 식단을 한 번에 붙여넣기 (날짜별 자동 분리)
- 대체식 사전에 우리 학교에서 자주 쓰는 대체 메뉴 추가
- 학년 말 진급 처리 버튼 (전체 학년 +1)
- NEIS 교육정보 개방 포털 급식식단 API로 식단 자동 불러오기
