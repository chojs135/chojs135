# 구글 시트에 가계부 올리기 (Windows, 처음 한 번)

가계부는 **구글 시트 "우리집 가계부"** 안에서 돌아갑니다.
- 데이터: 시트의 탭(거래내역, 카테고리, 예산, …)에 저장
- 프로그램: 구글이 무료로 실행 (집 PC를 켜 둘 필요 없음)
- 접속: 휴대폰·학교 PC·노트북 어디서든 **주소 하나**로, 각자 **구글 계정**으로 로그인

이 작업은 PC 한 대에서 **처음 한 번만** 하면 됩니다. 이후엔 PC를 꺼도 돼요.

## 1. 앱스 스크립트 API 켜기 (1분)

<https://script.google.com/home/usersettings> 에 가계부 시트가 있는 구글 계정으로 들어가서
**Google Apps Script API** 를 **사용**으로 바꿉니다.

## 2. 코드 받기

cmd에서:

```bat
cd C:\
git clone https://github.com/chojs135/chojs135.git gagyebu-app
cd gagyebu-app
git checkout claude/cool-cori-9u2yld
cd gagyebu
```

## 3. 올리기

```bat
setup-google.bat
```

1. 필요한 프로그램을 설치합니다 (몇 분).
2. 브라우저가 열리면 **가계부 시트가 있는 구글 계정**으로 로그인하고 **허용**을 누릅니다.
3. 끝나면 `https://script.google.com/macros/s/.../exec` 주소가 나옵니다. **이게 우리 가계부 주소예요.**

## 4. 처음 접속

1. 위 주소를 엽니다.
2. "Google에서 확인하지 않은 앱" 화면이 나오면 → **고급** → **우리집 가계부(으)로 이동(안전하지 않음)** → **허용**
   (우리가 직접 만든 앱이라 구글 심사를 받지 않아서 나오는 화면이에요.)
3. 이름, 가계부 이름, **Anthropic API 키**를 넣고 **시작하기**

## 5. 배우자 초대

1. **설정 → 구성원**에 배우자 이름과 **구글 계정 이메일** 입력 → 추가
   (구글 시트도 자동으로 공유됩니다.)
2. 배우자에게 가계부 주소를 보내고, 배우자도 4-2의 허용 과정을 한 번 거치면 끝.

## 휴대폰에서

주소를 열고 → 공유 버튼 → **홈 화면에 추가**하면 앱처럼 쓸 수 있어요.

## 새 버전 받기

제가 기능을 추가하면 `gagyebu` 폴더에서 `update-google.bat` 을 실행하세요. 주소는 그대로 유지됩니다.

## 문제 해결

| 증상 | 해결 |
|---|---|
| `User has not enabled the Apps Script API` | 1단계를 하고 1~2분 뒤 다시 실행 |
| 주소를 열었는데 "구성원이 아니에요" | 다른 구글 계정으로 열린 것. 브라우저 오른쪽 위에서 계정 전환 |
| AI 분석에서 "API 키가 올바르지 않아요" | 설정 → AI 분석에서 키 다시 입력 |
| 데이터를 실수로 지웠어요 | 구글 시트 → 파일 → 버전 기록에서 예전 상태로 복원 |
