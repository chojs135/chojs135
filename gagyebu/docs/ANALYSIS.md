## 공통적으로 쓸모 있던 기능 → 이번 MVP에 반영

1. **자동 분류 + 사용자가 고친 분류를 기억** (뱅크샐러드, Monarch)
   → AI가 분류하고, 사람이 고치면 가맹점 규칙으로 저장해 다음부터 우선 적용.
2. **이체는 지출이 아니다** (뱅크샐러드)
   → `이체` 구분을 따로 둬서 카드대금·적금·내 계좌 이체가 지출로 이중 집계되지 않게 함.
3. **월 요약: 수입·지출·남은 돈·전월 대비** (토스)
4. **카테고리별 지출 + 예산 대비 사용률** (편한가계부, YNAB)
5. **많이 쓴 곳 TOP N** (토스)
6. **누가 썼나 / 공동 지출** (Honeydue)
   → 거래마다 사용자(남편·아내·공동)를 지정, 대시보드에 사람별 합계.
7. **세부항목** (관리비 → 전기/수도/난방 등)
   → 대분류 + 세부항목 2단 구조.
8. **이상 지출 알림**
   → 최근 3개월 평균보다 30% 이상 늘었거나 예산을 넘긴 카테고리를 "체크포인트"로 표시.
9. **엑셀/시트로 내보내기**
   → CSV 다운로드 + 구글 시트 자동 동기화.

## 우리만의 차별점

- **입력 = 업로드**. 은행 PDF, 카드 엑셀/CSV, 영수증 사진, 관리비 고지서 스크린샷을 올리면
  Claude가 읽고 거래를 뽑아 분류한다. 저장 전에 검토 화면에서 한 번 확인·수정.
- **중복 방지**: 같은 날짜·금액·구분의 내역이 이미 있으면 "중복 의심"으로 표시하고 기본 제외.
- **확신도 표시**: 흐릿하거나 추측한 항목은 "확인 필요" 배지.

## 참고한 엑셀 가계부(디어나 가정용 ver 9)에서 배운 점

사람이 1년 동안 손으로 다듬은 가계부라 "실제로 매달 보는 것"이 잘 드러나 있었다. 구조만 참고했다.

| 엑셀 가계부 | 우리 앱에서 |
|---|---|
| 수입 / **저축** / 지출을 따로 기록, 저축률 = 저축 ÷ 수입 | `저축` 구분 추가(적금·청약·투자·대출원금). 남은 돈 = 수입 − 지출 − 저축 |
| `고정지출`을 하나의 대분류로 둠 | 고정 여부를 **모든 거래의 속성**으로. AI가 관리비·통신비·구독을 자동 표시하고 "고정 51만 · 변동 44만"처럼 나눠 보여 줌 (식비 안의 정기배송도 고정으로 잡을 수 있음) |
| 지출방법(카드)별 합계 | 결제수단별 지출 표 |
| 태그(반성, 확인필요) | 태그 + "#반성 N건" 체크포인트 |
| 캘린더 + 무지출 Day | 달력에 날짜별 지출, 🌱 무지출일과 개수 |
| 통합시트(대분류 × 12개월, 평균) | 연간 리포트(지출·수입·저축 표, 기록된 달 기준 월평균) |
| 소분류에 "(남편)/(아내)" 붙이기 | 거래마다 사용자 지정 → 카테고리를 사람 수만큼 늘릴 필요 없음 |
| 월별 시트 12개에 직접 입력 | 업로드하면 AI가 정리, 시트는 거래내역 하나 |
