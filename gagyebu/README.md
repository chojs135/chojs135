# 💰 우리집 가계부

부부가 함께 쓰는 웹 가계부. 은행·카드 내역서(PDF/엑셀/CSV), 영수증 사진, 아파트 관리비 고지서 스크린샷을
올리면 AI(Claude)가 거래를 뽑아 **지출/수입/저축/이체**, **카테고리·세부항목**, **고정지출 여부**로 분류해 준다.

- **설치 방법: [docs/GOOGLE-SETUP.md](docs/GOOGLE-SETUP.md)**
- 기존 앱 분석과 설계 이유: [docs/ANALYSIS.md](docs/ANALYSIS.md)

## 구조

서버를 따로 두지 않고 **구글 시트 + 구글 앱스 스크립트** 위에서 무료로 돈다. PC를 켜 둘 필요가 없다.

| 영역 | 기술 | 위치 |
|---|---|---|
| 화면 | React + Vite + TypeScript, Recharts → HTML 파일 하나로 빌드 | `client/` |
| 서버 | Google Apps Script 웹 앱 (`api(method, path, body)` 하나로 라우팅) | `gas/Code.js` |
| 시트 정리 | 참고용 엑셀 가계부와 같은 구성: **통합시트**(연간 상세표·차트), **1월~12월**(이달의 정리·결제수단·태그·예산·주간별·무지출 달력·고정지출/전체 내역) — 자동으로 다시 그려짐 | `gas/Reports.js` |
| 관리 탭 | 결제일 관리, 자산관리, 예비비, 대출 관리, 카드 관리, 통장관리, 이벤트 관리 (앱의 "관리" 화면과 같은 표, 시트에서 직접 고쳐도 됨) | `gas/Recurring.js`, `gas/Ledgers.js` |
| 데이터 | 연도별 거래내역 탭(`2026 거래내역`, 엑셀식 열: No·날짜·구분·내용·금액·대분류·소분류·지출 방법·태그·사용자…), 설정(보기용), 예산, 카테고리, 구성원, 자동분류규칙, 업로드기록 | 시트 |
| AI 분석 | Claude API (`claude-opus-5-5`, 구조화 출력, 스트리밍) — **브라우저에서 직접 호출** | `client/src/claude.ts` |
| 로그인 | 각자의 구글 계정. 웹 앱은 "접속한 사용자 권한"으로 실행되고 `구성원` 탭에 있는 사람만 통과 | |

Claude를 브라우저에서 부르는 이유: Apps Script의 외부 요청은 약 60초에서 끊기는데 긴 내역서 분석은 그보다 오래 걸릴 수 있다.
API 키는 시트의 스크립트 속성에 있고, 구성원 확인을 통과한 사람에게만 내려간다.

## 개발

```bash
npm run install:all
npm test              # gas/Code.js를 흉내 시트 위에서 검사
npm run dev:gas       # Apps Script 흉내 서버 (localhost:3002)
npm run dev:client    # 화면 (localhost:5173, ?as=이메일 로 사용자 전환)
npm run deploy        # 빌드 → clasp push → 웹 앱 배포 (주소 유지)
```

## 주요 기능

- AI 업로드 분석: PDF · JPG/PNG/WEBP(큰 사진은 자동 축소) · XLSX · CSV(EUC-KR 자동 인식), 여러 파일 한 번에
- 검토 화면: 항목별 수정/제외, 중복 의심·확인 필요·규칙 적용 배지
- 분류 학습: 분류를 고치면 가맹점 규칙으로 저장 → 다음 업로드부터 우선 적용
- 저축(적금·청약·투자·대출원금)은 따로 세서 저축률 = 저축 ÷ 수입, 카드대금·내 계좌 이체는 `이체`로 통계에서 제외
- 고정지출 자동 표시, 태그(#반성 #확인필요 …)
- **정기결제(결제일 관리)**: 매달 나가는 돈을 등록하면 결제일에 자동으로 그 달 내역에 기록(금액이 매달 다른 관리비 등은 '예정'으로만 표시), 지난 내역에서 반복 결제 추천, 시트의 `결제일 관리` 탭과 같은 목록
- 대시보드(간단): 수입·지출·저축·남은 돈, **어디에 썼나 / 수입은 어디로 갔나 원그래프**, 체크포인트, 🌱 무지출 달력 — **전체 / 남편 / 아내 / 공동** 보기 전환
  (예산·12개월 추이·결제수단·많이 쓴 곳·세부항목은 "자세히 보기"에)
- 연간: 원그래프 2개, 월별 흐름, 대분류 × 12개월 상세표(합계·월평균)
- 분류: 엑셀 가계부 기준(수입/저축/고정지출/식비/용돈/생활용품/의복·미용/건강/자기계발/경조사/문화생활/세금/교통/기부)
- 내역: 월별 목록, 검색·필터, 직접 입력/수정/삭제
- 관리: 결제일 관리(정기결제), 자산관리(순자산), 예비비(잔액·달성률), 대출 관리(상환 원금·남은 원금 자동), 카드 관리(이번 달 사용·전월실적 자동), 통장관리, 이벤트 관리(지난 수령일 알림)
- 설정: 구성원 추가(시트 자동 공유), API 키, 월 예산, 카테고리·세부항목 편집(이름 변경 시 기존 내역도 함께 변경), 자동 분류 규칙
